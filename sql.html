Employee Performance Mapping

Project: Employee and project data analysis for a simulated data science startup.

Objective

Use SQL to investigate employee performance, reporting relationships, departmental ratings, salary ranges, and experience to support workforce reporting.

Data preparation

Imported employee and data science team records, checked column types, and rebuilt the project table after identifying date-format incompatibilities during import. Dates were normalized to the MySQL YYYY-MM-DD format.

Methods

Applied filtering, concatenation, UNION, JOINs, subqueries, aggregate functions, and window functions including MAX, MIN, and RANK to report on performance and salary patterns.

Analytical insight

A manager-reporting query revealed that the president was listed as their own manager in the underlying records. This highlights why validating organizational data matters before using it to inform reporting decisions.

Example: reporting relationships

SELECT *
FROM emp_record_table AS e
INNER JOIN (
  SELECT MANAGER_ID, COUNT(*) AS Reporters
  FROM emp_record_table
  WHERE MANAGER_ID IS NOT NULL
  GROUP BY MANAGER_ID
) AS r
ON e.EMP_ID = r.MANAGER_ID;

This project demonstrates structured SQL problem-solving and data-quality checks. Findings reflect the simulated training dataset, not real employees.
